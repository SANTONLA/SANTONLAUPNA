# SANTONLAUPNA
🌐 Hello World Interactivo

¡Bienvenido a este proyecto web interactivo!
Este sitio demuestra cómo crear una interfaz visualmente atractiva y dinámica usando solo HTML, CSS y JavaScript, todo desarrollado en Visual Studio Code.

✨ Características

🎨 Interfaz moderna con gradientes, sombras y efectos animados.

💡 Alternancia entre modo claro y oscuro.

✍️ Texto animado letra por letra con interacción al pasar el ratón.

🎆 Efecto confetti al hacer clic o presionar una tecla.

🖱️ Efecto de resplandor que sigue el cursor.

💬 Botón para cambiar el mensaje del saludo.

🧩 100% sin frameworks ni librerías externas.

📂 Tecnologías usadas

HTML5 para la estructura.

CSS3 para estilos, variables y animaciones avanzadas.

JavaScript Vanilla para la lógica interactiva y efectos visuales.

Visual Studio Code como entorno de desarrollo.

🚀 Cómo usarlo

Clona este repositorio:

git clone https://github.com/tu-usuario/hello-world-interactivo.git
cd hello-world-interactivo


Abre el proyecto en Visual Studio Code (o el editor de tu preferencia).

Abre el archivo index.html en tu navegador.

Puedes hacer doble clic en el archivo, o usar una extensión como "Live Server" en VS Code para una mejor experiencia.

🧠 Detalles técnicos

Animaciones: Cada letra del título tiene una animación de entrada suave, con efecto de resalto al pasar el mouse.

Eventos:

click para lanzar confetti o cambiar el texto.

mousemove para mover el efecto de resplandor.

keydown con la tecla H para reiniciar el saludo y lanzar confetti.

Responsive: Adaptado a dispositivos móviles y pantallas pequeñas.

🎯 Objetivo del proyecto

Este proyecto fue creado como una práctica creativa para explorar interacciones en la web, transiciones suaves y estilos modernos sin necesidad de usar bibliotecas externas o frameworks complejos.

Ideal como introducción al desarrollo web moderno solo con tecnologías base.
